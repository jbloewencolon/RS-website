The Consent Domains Map

A relationship label is not blanket permission. This map separates consent into seventeen domains so that yes in one is not read as yes in all of them.

Mark where you stand in each domain, add a condition where it matters, then print it or read it aloud with the other person. There is no score and no correct pattern.

⌖ Safety — this tool is not appropriate when one participant is violent, coercive, retaliatory, or controlling. A written record of your limits can be used against you. If you are being controlled, reach a local domestic-violence or transformative-justice service before starting a joint conversation. Communication does not resolve every form of abuse.

⌖ Privacy — everything you type stays in this browser tab. Nothing is sent anywhere, nothing is stored, nothing is counted, and this page is disallowed to search crawlers. Closing the tab erases it.

After you fill it in

  • — Which domain did you hesitate longest over? That hesitation is the useful part, not the answer.
  • — Where did you assume a yes because of the relationship's name rather than an actual conversation?
  • — What would it cost you to move one domain to no? If the answer is housing, money, or access to children, the consent in that domain is not yet free.
  • — Set a date to look at this again. Consent is ongoing; a map is a snapshot.
